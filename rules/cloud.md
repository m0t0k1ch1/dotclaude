# クラウドセッションにおける規則

Claude Code のクラウドセッションで読み込む規則。

## クローンの管理

- GitHub への書き込み（`git push` の実行、Issue や PR の作成など）が必要なとき、リポジトリが非公開なとき、非公開かどうか分からないときは、クローンする前に `add_repo` でセッションに追加する。書き込みが必要なら `access: "push"` を付ける。事前にリポジトリの存在を確かめない（curl、`git ls-remote` などは使わない）。
- クローン先、クローンのコマンド、`register_repo_root` の実行方法は、`add_repo` の返答に書かれた指示に従う。クローンの配置を独自に決めない。
- Git の操作は `git -C <path>` で対象のリポジトリを明示する。
- 作業を始める前と報告するときに、どのリポジトリで何をしたかを明記する。
