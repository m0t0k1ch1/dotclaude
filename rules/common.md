# 共通規則

環境を問わず読み込む規則。

- メインエージェント（ユーザーと直接やり取りし、サブエージェントを起動できるエージェント）は、ファイルの作成、編集、削除を伴う作業を、変更するファイルの数や行数を問わず、自分で行わずにサブエージェントに委譲する。
  - メインエージェントが自分で行うのは、調査、計画、サブエージェントへの指示、サブエージェントが行った変更の確認である。
  - サブエージェントに指示するときは、作業の目的、対象ファイル、守るべき規則や制約など、作業に必要な情報をすべて指示の中に具体的に書く。
  - サブエージェントが行った変更を確認するときは、差分を読み、指示どおりに変更されているか、意図しない変更が混ざっていないかを見る。
  - 自分がサブエージェントとして起動されている場合（Agent ツールで起動され、委譲された作業を行っている場合）は、この項目を無視し、委譲された作業を自分で直接行う。
- 公開されている GitHub リポジトリ上のアイテム（Issue、コミット、PR、レビュー、コメントなど）に、プライベートな情報を書かない。Claude のセッションやアーティファクトを指す URL もこれに含む。
  - ツールが自動で付け足す場合も同じ。作成・編集した直後に本文を読み直し、該当する箇所を削除する。マージ前にも、コミットメッセージと PR の本文を再確認する。
  - Claude Code の署名として残してよいのは、次の 3 つだけ。コミットメッセージでは、`Co-Authored-By: Claude` に続けてモデル名と `<noreply@anthropic.com>` を書いたトレーラー。PR などの本文では、`Generated with [Claude Code](https://claude.com/claude-code)` の行（先頭に 🤖 が付くこともある）。Issue や PR のコメントでは、`Generated by [Claude Code](https://claude.ai/code)` の行。
