# クラウドセッションにおける規則

Claude Code のクラウドセッションで読み込む規則。

- GitHub への書き込み（`git push`、PR、Issue など）が必要なとき、リポジトリが非公開なとき、非公開かどうか分からないときは、クローンする前に `add_repo` でセッションに追加する。書き込みが必要なら `access: "push"` を付ける。事前にリポジトリの存在を確かめない（curl、`git ls-remote` などは使わない）。
- クローン先、クローンのコマンド、`register_repo_root` の呼び方は、`add_repo` の返答に書かれた指示に従う。独自の配置をしない。
- Git の操作は `git -C <path>` で対象のリポジトリを明示する。
- コミットするときは、ファイルを個別に指定して `git add` する。`git add -A` と `git add .` は使わない。
- 作業を始める前と報告するときに、どのリポジトリで何をしたかを明記する。
